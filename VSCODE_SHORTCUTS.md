# VS Code Keyboard Shortcuts
My favorite VS Code Shortcuts.

## Navigation

| Function | Key |
| --- | --- |
| Backticksc | Fn Esc |
| Open Folder | Ctrl K O |
| Search File | Ctrl P |
| Search Entire File | Ctrl Shift F |
| Go to Function | Ctrl Shift O |
| Go to Line | Ctrl G |
| Start End | Fn { PgDn |
| File Start End | Ctrl Fn { PgDn |

## Editing

| Function | Key |
| --- | --- |
| Delete Line | Ctrl Shift K |
| Duplicate Line | Shift Alt Up Down |
| Select Full Line | Ctrl L |
| Move Line | Alt Up Down |
| Line Comment | Ctrl / |
| Block Comment | Shift Alt A |
| Emmet Wrap | Ctrl E R |
